{# obddesk override of the framework's _sidebar.html. Replaces the generic "MODELS" section header with a project- specific "DIAGNOSTICS" header and gives each obddesk model a thematic inline SVG glyph instead of the framework's default `table` icon. The framework's `entries` variable is intentionally NOT iterated — obddesk hardcodes the four model rows because this is a project-side override (it knows its own catalogue). Adding a 5th model means editing this file alongside the `Admin::new().model::()` call in main.rs. The Auth section is byte-identical to the framework copy. All SVGs use `stroke="currentColor"` so the chrome-scope cascade in `layout/shell.css` tints them light-on-dark automatically. The active-link state is handled by the framework's existing `.is-active` CSS — no JS, no template logic needed. #}
