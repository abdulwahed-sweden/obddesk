Operator workflow

  1. Register the vehicle. Add a new VIN with make, model, model year, engine displacement, and fuel type.
  2. Open a scan session. Create a scan session against the vehicle's VIN, recording mileage and the technician.
  3. Record detected faults. For each DTC observed during the scan, file a detected fault referencing the session and the diagnostic code.
  4. Resolve and document. Edit the fault row, set is resolved, and capture a resolution summary the next technician can rely on.
